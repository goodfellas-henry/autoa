# AutoA（オートア）

Base 上の Uniswap V3 で、自分の資金だけを自動運用する仕組みです。
ETH/USDC と BTC/ETH（cbBTC）に対応し、ペアごとに金庫を1つずつ作ります。

- `index.html` ほか … 操作画面（GitHub Pages で公開して、MetaMask アプリ内のブラウザで開く）
- `bot/` … 運用ロボット（エックスサーバーVPS などで 24 時間動かす。1台で複数の金庫を担当）
- `contracts/` … 金庫のプログラム本体とテスト（参考用）
- `MyLPVault.abi.json` … BaseScan から直接操作する時に使う説明書きファイル

設置方法は「AutoA 設置手順書」を参照してください。

## 安全の約束（プログラムで強制）
1. 持ち主は金庫を作った財布で固定。後から変えられない。
2. お金を外へ出す操作は持ち主しかできず、送り先は必ず持ち主。
3. ロボットにできるのは「範囲の追従」と「手数料の回収」だけ。交換も、範囲の指定もできない。
4. 価格が急に動いた直後は、組み直しを拒否する（平均価格との比較）。
5. プログラムの書き換え機能はない。

## 絶対に守ること
- MetaMask の「秘密のリカバリーフレーズ」は、どこにも入力しない（このシステムでも一切使いません）。
- `bot/.env`（ロボットの鍵）は GitHub に上げない（`.gitignore` で除外済み）。
- ロボットの財布には、ガス代分の少額の ETH だけを入れる。
- 操作画面は、自分の GitHub Pages の URL からだけ開く。
